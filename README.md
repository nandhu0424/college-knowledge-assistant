# College Enterprise RAG

This project provides a basic RAG pipeline for college enterprise knowledge retrieval and answer generation.

## Structure

- `backend/` - application logic
- `data/` - raw, processed, and sample document storage
- `.env` - environment configuration
- `requirements.txt` - Python dependencies

## Usage

1. Install dependencies:
   `pip install -r requirements.txt`
2. Add source PDFs under `data/raw/`
3. Run the backend pipeline from `backend/main.py`
